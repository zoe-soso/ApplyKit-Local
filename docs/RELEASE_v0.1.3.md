# 本地网申助手 · ApplyKit 中文增强版 v0.1.3

基于 [DeepestWind/ApplyKit](https://github.com/DeepestWind/ApplyKit) 固定提交 `4f3cb1a7e3c47b4c674f4d3c19e63c57793ab838` 整理的中文增强版，保留原项目与第三方许可，修改沿用 MIT。

## 本版特点

- 中文资料模板、导入校验和预览，兼容原有 ApplyKit JSON。
- 日期精度不足时提示补充，不猜月份或日期。
- 多条项目独立填写，未适配的校园实践、技能等分区保持待处理。
- 修复校验提示充当字段名、只读下拉、电话区号及SPA重新扫描等问题。
- 增加未完成字段原因、建议和不含填写值的诊断导出。
- 保留三项生产权限，扩展页面禁止外部连接。

本地存储、无云端模型、通用引擎及Moka/北森/飞书适配等基础能力来自原项目。

## 下载与更新

下载附带的 `本地网申助手-离线版.zip`，解压后在 Chrome / Edge 扩展管理页开启开发者模式，加载其中的 `本地网申助手/扩展` 目录。

已有用户在扩展管理页点击“重新加载”，刷新招聘页即可；无需卸载或重新导入履历。网页已保存的错误内容需本人更正。
